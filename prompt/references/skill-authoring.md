# 技能编写路由

这是参考指针，不是单独的 `skill-creator` 技能。

- 编写 agent 消费的文档：读 [writing-for-agents](../../writing-for-agents/SKILL.md)。
- 优化技能的触发、工作流或评测，或用户要求打包/发布：读 [yao-meta-skill](../../yao-meta-skill/SKILL.md) 并选对应轻量路线。
- 一次性 prompt 改写留在 [prompt](../SKILL.md)，不自动升级成技能包。

保持名称和实际目标路径稳定；按需展开资料，不导入未安装的 CLI、评测 viewer 或另一宿主的子代理调用协议。
