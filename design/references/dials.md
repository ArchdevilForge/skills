# Optional design dials

Use only when numeric shorthand helps discuss a design direction. They are descriptive, not configuration or acceptance gates; no baseline must be applied.

| Dial | Low | Medium | High |
|---|---|---|---|
| DESIGN_VARIANCE | Familiar, symmetric layout | Selective asymmetry | Experimental composition |
| MOTION_INTENSITY | Static and direct feedback | Restrained transitions | Deliberate choreography |
| VISUAL_DENSITY | Few elements, generous space | Everyday product density | Dense comparison/analysis |

Choose values from the brief and existing design. Layout must work at narrow widths regardless of variance. Motion must honor reduced-motion preferences regardless of score. Dense interfaces may still need cards; low-density pages may still need tables.

Use native CSS when sufficient. For an actual pin/scrub requirement, see [motion examples](motion.md). A dial never creates a requirement for a new dependency, animation or theme.
