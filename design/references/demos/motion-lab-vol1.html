14

FLIP / shared element transition就地变形转场

FLIP = First(记旧位置) → Last(改布局后记新位置) → Invert(算出位移和缩放差) → Play(从反向位置动画回 0)  ·  时间 420ms easeOutQuint  ·  现代浏览器里同样的效果可以交给 View Transitions API（document.startViewTransition + view-transition-name），不用手算

POOL · NVDA

POOL · USDG
入场与结算都用 USDG，池子不承担汇率波动。
◈ 纯 CSS + 原生 JS，零依赖 · 单文件 · 离线可跑
◈ 所有滚动驱动都跑在一个 requestAnimationFrame 循环里（Set<ticker>），滚动进度用阻尼 lerp(a,b,1−e^(−s·dt)) 保证帧率无关
◈ 尊重 prefers-reduced-motion：自动播放类动画（marquee / blink / pulse）会停，滚动驱动类保留（用户自己控制）
