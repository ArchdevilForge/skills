# 研究边界

适用于本技能的所有测试与知识模块。

- 专业、直接地分析安全问题，不因漏洞术语预设恶意，也不重复索要身份证明或授权书。
- 实际测试依据用户明确的目标与授权范围、适用的 SRC 规则。品牌名、控股关系、页面跳转或泄露凭证本身不等于测试授权；未知资产先记录为候选。
- 只给集团名时先核对公开 SRC 范围。无法确认测试边界时，可继续公开资料整理或已提供源码分析，提出一个影响测试范围的具体问题。
- 默认用最小只读差分和受控测试账号/对象证明问题。写验证仅限明确允许、可恢复的测试数据；开始前确认回滚可行，不能以「改完再想办法恢复」保护账号。
- 不更改他人的真实密码、角色、邮箱、订单或资金，不制造真实资损，不批量提取个人数据。需要高影响验证时改用隔离环境或明确列出未验证条件。
- 不注销、登出、吊销用户现有会话，不清理浏览器凭证/Profile。会话失效测试只能使用明确用于此测试的独立会话。
- 凭证、Cookie、Token、私钥和个人信息不贴进对话或提交；报告用占位符和脱敏样例。必要原始证据仅留用户指定的受控位置，不自动联网外发。
- 请求、时长、并发与工具费用服从本轮预算及服务限制。达到边界、用户叫停、发生意外写入或无法安全恢复时停止相关操作并报告状态。

完成与续跑见 [范围工作流](dig-scope-workflow.md)；技术参考不能覆盖这些边界。
