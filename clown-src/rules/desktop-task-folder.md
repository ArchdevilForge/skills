# 任务目录与清理

仅在实际需要研究产物时使用；普通问答、技能维护和只读代码审查不创建桌面任务目录。

## 产物位置

用户指定路径优先。否则使用系统实际桌面目录下的 `{目标}_SRC挖洞/`，桌面不可用时选当前工作区并说明位置；不硬编码 Windows 路径。

按需创建：

| 路径 | 内容 |
|---|---|
| `资产/` | 范围依据、URL 清单、多资产任务队列 |
| `js/` | 从站点提取且有分析价值的前端文件 |
| `报告/` | 正式漏洞报告 |
| `{名}_dig/` | 临时脚本、日志、缓存和复现状态 |

一任务一根目录，续跑复用原目录，不覆盖旧队列。简单任务不预建空文件、README 或线程交接模板。正式报告与原始敏感证据分离，遵守 [研究边界](security-research-context.md)。

## 清理

仅在用户要求清理时处理明确指定的任务路径：先列出实际将删除/保留的对象，确认有无用户材料和需要保留的证据。无报告不等于整个目录可丢弃。

- 保留正式报告、资产和用户提供的文件；只清理已确认可丢弃的任务缓存。
- 模糊的「清理」不能授权删除所有桌面任务、整个项目或未识别的文件。
- 递归删除、不可恢复的原始证据清理或范围不明确时先确认；不随任务结束自动删除。
- 不动浏览器账号密码、Cookie 库、Profile、自动填充和用户真实会话。仅本任务自建临时缓存可按上述范围清理。
