# 知识作为辅助

用现场证据与业务意图选择分析路径；技能和清单提供经验，不是必须逐条执行的剧本。

- 对应模块能解决当前问题时才读；没有匹配模块也可继续分析，不为触发技能而停工。
- 清单未覆盖的新技术仍可研究，但方法不能扩大用户授权或绕过 [研究边界](security-research-context.md)。
- 同一含义只保留一个来源。报告看 [报告格式](vuln-report-format.md)，范围看 [范围工作流](dig-scope-workflow.md)，知识维护看 [维护规则](hunt-iter.md)。
- 只有明确要求沉淀经验时更新知识；默认研究任务不自动修改已安装技能。
