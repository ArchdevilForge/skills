# Clown SRC package maintenance

本文件只约束此技能包的维护，不将安全研究流程施加到普通工程或文案任务。

- `SKILL.md` 负责路由；`rules/` 保存工作流；`知识库/` 保存按类型读取的参考。使用包内相对链接，不依赖原作者机器上的配置目录。
- 修改规则时检查入口、索引与调用该规则的文档，修复冲突来源，而不是叠加一条「最高优先级」。
- 保留研究范围、最小影响、会话与凭证保护，以及报告证据边界。知识里的测试手法不构成对线上目标执行的授权。
- 普通维护不启动浏览器、不调用测绘服务、不写研究知识库、不修改全局代理或账号配置。
- 更改路由后检查正反例及链接；更改工具命令后用本机 `--help` 或官方文档核实。未实际测试的能力不宣称通过。
