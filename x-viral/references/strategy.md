# crypto+AI X 账号运营策略

## 双平台内容配方（核心认知）

**推特 = 利益叙事；小红书 = 学习资产。** 同一事件，两个角度，最省力的打法：

| 事件 | 推特角度（赚钱向） | 小红书角度（学习向） |
|------|------------------|-------------------|
| 模型开源 | 这模型能跑什么赚钱的活？谁靠它赚到钱了 | 怎么装、怎么用、3 步教程 |
| 新 API 免费 | 免费额度能套什么利 | 完整接入教程 + 避坑 |
| 价格/热点事件 | 站队：该买还是该卖 | 科普：来龙去脉讲清楚 |

- 推特：算法重 reply/转发，钱是最强评论引擎，利益相关引站队引转发。真假可以模糊（推测/有人说），但别编造具体事实——造谣是封号线
- 小红书：官方 CES 评分里收藏权重高，60% 流量来自搜索（用户当百度用）。教程/清单/避坑/对比表收藏率天然高，收藏 = 实用价值信号 = 进更大流量池

## 爆款公式（热点 + 价值）

> 热点是钩子，干货是主食：热点事件/词 + 你的领域 + 具体解决方案 = 高潜力爆款

- 蹭热点 3 秒法则：关联度（能链接到账号定位吗）、差异度（有新视角吗）、延展度（明天还有热度吗）
- 标题 5 密码：蹭热点、情绪化、数字化、关键词布局（搜索长尾）、IP 记忆点
- 实用类 6 模式（新闻转实用的路径）：合集、测评（红黑榜）、科普、避坑、教程、攻略
- 纯新闻 = 转发新闻，不触发收藏和评论；写文章写的是「事件本身」（含证据链），不是「关于讨论的评论」

## 标签策略（三平台机制完全不同）

**小红书（标签是主要杠杆）**：3-6 个最佳，超 10 个判定堆标签降权
- 分层：热层 1-2（百万级话题搏推荐）+ 中层 2-3（10-100 万，主流量）+ 长尾 1-2（<10 万，搜索精准流量）
- 顺序：前 3 个核心标签放正文开头第一段后（算法优先读），其余放文末
- 红线：挂无关热门话题 = 蹭流量降权；极限词（第一/必买）不能进标签；地点标签计入 10 个限额
- 找官方流量话题：创作灵感/每周笔记灵感（有官方助推流量的活动话题，类似抖音精选标签）

**X/推特（标签近乎无用）**：0-1 个，最多 2 个；3 个以上触发 spam 分类器，reach 可砍 40%
- 算法语义理解正文（Grok 读全文），关键词写进正文句子比标签有用
- 只在活动 tag（#WWDC26 类）、品牌 campaign、niche 社区（#BuildInPublic 类）时用；观点帖 0 标签；thread 最后一帖 1 个

**抖音参考（存在官方流量标签）**：金色「精选」徽章话题 + 创作者中心「流量扶持中」标签有真实流量加成，但必须内容匹配，挂不相关照样降权。别把抖音那套搬到 X

## 定位（决定一切）

- **窄**：选一个细分赛道——链上数据+AI agent / AI x DeFi 投研 / Crypto AI 基建追踪。杂货铺账号没人关注
- **个人账号 > 品牌账号**：crypto 圈共识，创始人/个人 IP 更可信
- **bio + 置顶帖 = 转化页**：访客点进来 3 秒内要明白「这人是干嘛的、为什么值得关注」
- 两三个主题反复讲，形成「提到 X 就想到你」的占领

## 内容配方（每周结构）

| 类型 | 占比 | 说明 |
|------|------|------|
| 教育 | 25-30% | 解释机制/市场/赛道，真正有用的知识，不是营销 |
| 观点 | 20-25% | 明确可辩护的立场，不是「web3 改变未来」 |
| 社区 | 15-20% | 转推/互动生态里的 builder、研究员（互惠放大） |
| 运营 | 15-20% | 项目进展，用「告知」语气不用「宣布」语气 |
| 反应 | 10-15% | 蹭热点、quote 大号加增量观点 |
| 促销 | ≤20% | 超过这个比例就开始掉粉 |

## Thread 是最高杠杆形态

- Thread 3-10 条：48-72h 持续互动，被引用数周，书签率高
- **钩子 = 整个 thread**：首帖首小时互动决定一切。首帖弱 = 后面全隐形
- 每条自包含：一个点说清，读两遍还看不懂就拆成两条
- 结尾必须有结论：「The takeaway: …」给读者一个可直接转发的总结
- 配图：简单柱状图 > 复杂信息图（简单图表在 visual tab 里还能二次曝光）
- 发完 3-6 小时自回一条补充/抛问题：制造第二互动窗口

## 冷启动（前 2-4 周最痛苦）

- 每天 2-5 条，雷打不动；算法有 new-author boost，别浪费扶持期
- 每天花时间在大 V 评论区写高质量回复：更锐的角度、更清晰的解释、数据点 —— 不是「Great post!」
- 大 V 回复你一次 ≈ 你自嗨 50 条（你的帖子进入 ta 的互动网络候选池）
- Quote 大号帖子 + 一句增量观点，是借量的标准动作

## 时机与节奏

- 每天 3-5 条，5 天/周 + 每周 1 条精品 thread
- 峰值窗口（美东时间）：9-11am（美股开盘）/ 2-4pm（欧洲下午）/ 8-10pm（亚洲早上）
- 60 分钟窗口规则：发帖后 1 小时内回复所有评论，首小时互动决定是否推大流量
- 快讯类内容（链上异常、巨鲸异动、协议攻击）拼的是速度，先发比完美重要

## 复盘指标（每周看）

| 指标 | 目标 |
|------|------|
| engagement rate | 3-5%（<50k 粉账号） |
| profile visit → follow 转化 | 1-3% |
| 粉丝月增长 | 5-10% |
| 书签率 | 高 = 内容有深度价值，重点关注 |

- 砍掉 engagement < 3% 的格式；复制爆款格式（拆结构，不抄内容）
- 曝光高但涨粉差 → 问题在 profile 转化，不在内容

## 红线（做了就废号）

- 买粉/互刷：X 检测协调不真实行为，限流或功能受限
- 只发自己：内容全是自我推销 = 掉粉
- 不回评论：首年每条有意义的回复都要回
- 外链塞正文（尤其 YouTube/Telegram）：限流，放评论区或 bio

## 变现路径（前 3 个月别想）

订阅/付费长文 → 咨询/投研报告 → 广告。前期只做一件事：涨粉 + 互动数据。
