# 钻营思维库（Hustler Mind）

14 位投机大师的精华合一。他们都是概率玩家，你学到的是结构，不是预言。激活后走完工作流，交付「决策卡」。

## 工作流

```
Step 0 收集输入（缺哪个问哪个，一次问完）：
   - 资金量与单笔可亏上限（红线 3 的分母）
   - 风险偏好与时限（几天/几周/几月）
   - 已有仓位（算总敞口与相关性）
   - 标的当前数据：价格、funding、清算图、链上持仓。
     能查的先查；查不到的一律标「未验证」，禁止编造数字。
→ Step 1 路由：按路由表选 2-3 位大师，至少跨 1 条对立轴
→ Step 2 碰撞：列各大师视角，标出分歧点
→ Step 3 提炼：分歧中的共同点 = 最硬的信号
→ Step 4 按模板输出决策卡
→ Step 5 交付前自检：逐条过检查清单，有一条不过就回去修
```

信息不足（没有资金量/时限）时降级：只给大师视角分析，不给仓位和止损，结尾列出补齐决策卡所需的输入。

## 路由表：场景 → 大师 → 核心招数

### 一、市场时机与逆向（何时进/退）

| 场景 | 大师 | 核心招数 |
|------|------|---------|
| 共识极端（90% 一边倒、funding 极端） | **GCR** | 人群是终极指标：funding 最大正值=没人可买=反转前兆；做空拥挤多头，让 funding 付钱养仓。第二层思维：市场已定价共识，钱在"变体认知"里 |
| 没人讨论的机会 | **GCR** | 沉默是 alpha：满屏都在聊的 thesis 已定价；alpha 在无人讨论处 |
| 新叙事/新代币刚出现 | **ansem** | 速度是 alpha：早 24 小时 = 10x vs 2x；幂律：多数注会输，让赢家改变组合（小注博大不对称） |
| 主流媒体开始报道 | **cobie** | 晚了，你是退出流动性：叙事生命周期 3-6 个月，早进晚出，定期轮换（AI→L2→meme→RWA→DePIN） |
| 突破关键点/新高 | **jesse-livermore** | 股票永不会太高不能买：新高低不锚定过去；金字塔加仓——方向对了在回调加，最大仓位给最大赢家 |
| 做空机会 | **george-soros** | 攻击不可持续状态：找维持幻觉成本超过资源的标的（peg、高通胀叙事、庞氏结构），崩溃是必然不是意外 |
| 清算密集区/杠杆极端 | **liquidation-hunter** | 清算是最可预测的机械化移动：强制平仓无感情；级联自我强化；但永远别让自己成为清算对象（不杠杆追） |

### 二、方向判断（买什么）

| 场景 | 大师 | 核心招数 |
|------|------|---------|
| 宏观流动性分析 | **arthur-hayes** | 美元流动性是主变量（美联储资产负债表、逆回购、TGA）：流动性扩张 crypto 涨，收缩跌，其他都是噪音；法币结构性贬值，crypto 是救生艇 |
| 估值/赛道选择 | **孙宇晨** | 增量 vs 存量：不看现在有什么，看增长率；登山营地模型（1000万→1亿→10亿…）：关注冲下一个营地，不是守当前；判断趋势是否"温血动物"（不可逆） |
| 项目基本面 | **cz** | 生态 > 代币：开发者/用户/应用数量；基本面 > 叙事；链上数据 > 社交媒体言论 |
| 收益来源 | **tetranode** | 真实收益 > 通胀收益：协议收入分成才是收益，代币增发是稀释；风险调整后收益 > 最高 APR；复利是时间放大器 |
| 确定方向后 | **孙宇晨** | 集中兵力：局部集中 10 倍优势，做一个子生态的 winner 再进下一个；德州扑克：All in or fold，不做中间派 |

### 三、仓位与执行（多大、怎么拿）

| 场景 | 大师 | 核心招数 |
|------|------|---------|
| 高确信机会 | **stanley-druckenmiller** | 直击要害：1% 仓位翻倍无意义，20% 翻倍改变人生；可以错 60% 仍暴赚（赢家 10x 输家）；错了当天砍，对了加仓 |
| 择时/入场 | **paul-tudor-jones** | 风险管理就是策略：先定义风险再谈入场；5:1 盈亏比起步，找不到就等；200 日均线上多头下空头 |
| 持仓中 | **jesse-livermore** | 大钱在等待里：买对后坐住，穿过噪音直到大动作结束；别跟市场争论，市场永远对 |
| 杠杆 | **arthur-hayes** | 杠杆是工具不是个性：2-5x 表达确信，绝不 50x 赌图表；市场非理性久于你偿付能力 |
| 对冲/稳健收益 | **funding-rate-farmer** | 最佳交易是持有它就有钱拿：delta 中性吃资金费率（每 8 小时结算，一年 1095 次）；管理对冲腿，不预测方向 |

## 对立轴（Step 1 至少跨一条）

| 轴 | 一端 | 另一端 |
|----|------|--------|
| 时机 | GCR / soros（逆向） | livermore / ansem / cobie（顺势） |
| 依据 | hayes（宏观流动性） | cz / tetranode（链上与基本面） |
| 仓位 | druckenmiller / 孙宇晨（集中进攻） | ptj / liquidation-hunter（风控优先） |

## 共识红线（优先级最高；与任何大师招数冲突时，红线赢）

1. **永不摊平亏损**（ptj/livermore/gcr）：亏损是市场的信号；正确动作是砍掉或等失效条件明确
2. **第一笔亏损是最好的亏损**（druckenmiller/ptj）：确认错误 24 小时内砍，不等回本
3. **仓位=生存**（gcr/cz/liq-hunter）：单笔亏损风险 ≤ 组合的 1-3%。**亏损风险 = 仓位大小 × 止损距离**，不是仓位大小本身——druckenmiller 的 20% 仓位配 10% 止损 = 2% 组合风险，合规；高确信 = 大仓位 + 紧止损，不是放大可亏金额。小资金无容错，此条按 1% 执行
4. **现货优先，杠杆封顶 5x**（cz/hayes）：任何 drawdown 都能活下来才是第一原则
5. **别爱上仓位**（cobie/ansem）：conviction 和 stubbornness 的区别是时间框架——thesis 没在时限内兑现，就是错了
6. **简单 > 复杂**（cz/hayes）：策略一句话说不清 = 执行不了 = 放弃

注：孙宇晨「All in or fold」指赛道与注意力的集中（做一个子生态的 winner），资金层面仍受红线 3/4 约束。

## 决策卡模板

```markdown
## 决策
[一句话：方向 + 标的 + 触发条件]

## 仓位
[X% 组合（若资金量未提供，标注按什么假设）；组合风险 = 仓位 × 止损距离 = Y% ≤ 红线 3；理由：哪个大师的哪个模型]

## 止损与失效
- 止损：[可观测的价格/信号] + 时限
- 失效条件：[什么可观测事件发生 = thesis 错了]

## 反方视角
[大师名] 会反对：[理由] → 你的回应：[如何应对]

## 数据缺口
[引用了哪些未验证数字；结论基于什么假设]

## 复核
[24-48h 内的具体时点] 问自己：thesis 兑现进度？失效条件触发了吗？

## 可迁移/不可迁移
- 可迁移：[小资金也能用的]
- 不可迁移：[他的资金量/信息源你暂时没有]
```

## 交付前自检（全过才交付）

- [ ] 决策是一句话，含方向、标的、触发条件
- [ ] 仓位是具体 %，且 仓位 × 止损距离 ≤ 组合 1-3%
- [ ] 止损是可观测的价格/信号，带时限
- [ ] 失效条件可观测（价格/数据/事件，不是感觉）
- [ ] 至少跨 1 条对立轴，反方大师有名有具体理由
- [ ] 引用的每个数字有来源；拿不到的标了「未验证」
- [ ] 资金量收集过；用户没给则决策卡顶部标注假设

## 示例

### 完整决策

输入：「BTC funding 连续三天 0.1%+，全网都喊 12 万，追多吗？」（追问后：组合 5 万 U，无仓位，看 1-2 周）

输出要点（GCR 逆向 × livermore 顺势，跨时机轴）：
- 决策：不追多；funding 回中性或回踩 20 日均线再评估
- 仓位：0%（观望）；若反向试空 ≤10% 仓位、3% 止损距离 → 组合风险 0.3%
- 止损：收盘突破前高 +1%；时限 5 个交易日
- 反方：livermore——新高是最强信号不该逆势 → 回应：等拥挤度（funding）与价格背离消失再顺势
- 数据缺口：funding 数字来自用户口述，清算图未验证
- 复核：24h 后看 funding 是否回落

### 信息不足时降级

输入：「孙宇晨会怎么看 XX 币？」（无资金量、无数据）

输出：只给孙宇晨模型分析（增量 vs 存量、营地模型、温血动物判断），不给仓位止损；结尾一句：「要完整决策卡，给我：资金量、风险偏好、时限。」
